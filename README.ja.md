# EmDash Featured Post

[English](README.md) | [繁體中文](README.zh-TW.md) | 日本語

ホームページに掲載する注目記事を記事編集画面から選べる、EmDash の**ネイティブプラグイン**です。既定の上限は 1 件で、管理者は 1〜20 件に変更できます。上限に達した場合は、先に別の記事の指定を解除してください。


**テーマへの組み込みが必要です：**プラグインは記事を選択します。表示するには、サイトのテーマに組み込んでください。詳しくは下記の統合手順をご覧ください。

## 互換性と制限

- ローカルの Cloudflare Workers 模擬環境で、EmDash と `@emdash-cms/admin` **1.3.1** を使って検証しています。
- サンドボックス型ではない、信頼されたネイティブプラグインです。サイトの依存パッケージとしてインストールしてください。EmDash のサンドボックス型プラグイン registry からはインストールできません。
- サンプルはコレクション `posts`、画像フィールド `featured_image`、記事 URL `/posts/<slug>` を前提としています。実際のサイト構成に合わせて変更してください。
- 注目記事に指定できるのは保存済み・公開済みの記事です。指定は記事の保存ボタンとは別に即時保存されます。
- プラグインは記事 ID とスラッグを設定に保存し、記事本文は変更しません。非公開・削除・スラッグ変更で取得できなくなった記事はサンプルで除外され、有効な注目記事がない場合は画像付きの最新記事を使います。スラッグ変更後は再指定してください。

## 権限と信頼境界

記事の参照には `content:read` を宣言しています。注目記事の指定には利用者の `content:publish_any` 権限が必要です。選択内容はプラグインの設定に保存し、記事を書き換える API は使用しません。

ネイティブプラグインはサイトと同じプロセスで動作し、サイトの依存パッケージとしての権限を持ちます。**サンドボックスによる隔離はありません。** 宣言した権限は使用する EmDash API を示すもので、ネイティブコードの動作範囲を制限するセキュリティ境界ではありません。コードを確認し、信頼できるものだけをインストールしてください。

## インストール

現在 npm には公開していないため、EmDash サイトのプロジェクトで GitHub からインストールします。

```sh
npm install github:joyce5438/emdash-Featured-Post#v0.2.0
```

`astro.config.mjs` で読み込み、既存の EmDash `plugins` 配列に追加します。

```js
import { featuredPostPlugin } from "emdash-featured-post";

// emdash({ ... }) 内：
plugins: [
  featuredPostPlugin(),
  // ...その他のプラグイン
],
```

サイトを再ビルドしてデプロイしてください。**プラグインだけではホームページは変更されません。** 以下の連携が必要です。

## 設定とホームページ連携

管理画面のプラグインメニューから「Featured-Post」を開き、注目記事の上限を設定します。選択済み件数より小さい上限に変更する場合は、先に余分な記事の指定を解除してください。設定画面には記事タイトルとスラッグが表示され、削除済みの記事の指定も解除できます。

ホームページでは `getPluginSettings("home-featured")` から `state.selected` と `state.limit` を読み、`getEmDashEntry` で公開済みの記事を取得して ID を確認し、サイトのレイアウトで表示します。有効な指定がなければ従来の自動選択を使い、通常の記事一覧から注目記事を除外して重複を避けます。[examples/homepage.astro](examples/homepage.astro) を参考に、既存のホームページに合わせて実装してください。

**0.1 からのアップグレード：**既存の指定は保持されます。ホームページも新しい `state` を読むように変更し、`state` が存在しない場合のみ旧 `selected` を参照してください。旧設定だけを読み続けると、アップグレード後の変更は反映されません。複数記事の表示にはホームページ側の対応も必要です。

## キャッシュと利用量

**このプラグインはホームページのキャッシュを変更・無効化しません。** ページキャッシュがある場合、期限切れまたはキャッシュ削除まで古い注目記事が表示されることがあります。サイトが対応していれば、変更後に対象ページのキャッシュだけを削除する方法もあります。

即時反映が必要な場合、サイト管理者はホームページのページキャッシュを無効にすることもできます。ただし、キャッシュ利用時よりホームページへのリクエストとデータベース読み取りが増え、利用量や費用に影響する可能性があります。これは任意であり、各サイトのキャッシュ設定で行ってください。
